## 给实现 Agent 的方式

将本包的三个编号主文档一起交给 Codex。建议存入目标仓库的 `docs/desktop/`，再使用任务书第7节的启动提示词。主规范负责“做什么与边界”，任务书负责“按什么顺序做”，测试清单负责“怎样知道确实做成”。

不要只给实现 Agent 一段摘要，也不要只给HTML截图。Markdown包含任务、字段、状态和负例，适合检索与逐步执行。
