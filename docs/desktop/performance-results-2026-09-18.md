# 本地容量基准

执行时间：2026-09-18（Asia/Shanghai）

## 结果

在当前 Mac 上，10 位成员、500 份纯合成文档、50,000 条纯合成指标的完整 Dashboard 快照读取，12 次热缓存样本：

| 项目 | 结果 |
|---|---:|
| 最小值 | 485.8 ms |
| 中位数 | 518.0 ms |
| P95 / 最大值 | 559.6 ms |
| 规范目标 | P95 ≤ 1,000 ms |
| 判定 | PASS |

合成数据集建立耗时 2,691.3 ms；整次基准（含预热和 12 次读取）10,119.8 ms。本次结果来自 `pnpm check` 的常规门禁执行，不再只依赖单独手动命令。

## 环境与边界

- 平台：darwin-arm64
- CPU：Apple M2 Max，12 个逻辑核心
- 内存：96 GB
- Node：v23.9.0
- 数据：脚本临时生成的纯合成成员、文档、来源定位和指标，完成后删除临时工作区
- 测量对象：当前实现为 Renderer 准备的完整 `DashboardSnapshot`；不是 AI 延迟、安装冷启动或低配置机器结论
- 缓存：先预热 2 次，再记录 12 次；因此只支持 NFR02 的当前机器热缓存判断

复现命令：`pnpm benchmark:local`。跨平台、8 GB 参考机冷启动和持续导入仍需对应目标环境实测。
