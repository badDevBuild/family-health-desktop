# 隐私与数据边界

| 数据 | 默认位置 | 何时离开本机 |
|---|---|---|
| 原始报告字节 | 本机对象库 | 只在获授权的处理任务中，按受控片段或页面作为 Codex 输入 |
| 规范化文本与图片页 | 本机临时目录 | 授权任务中发送必要输入；任务后清理临时文件 |
| 已接纳事实、用户补充、派生说明 | 本机 SQLite | 仅在用户授权刷新派生说明时发送必要上下文 |
| 去标识化医学搜索词 | Codex 内置 Web Search | 仅在综合分析与派生安全复核中按需查询通用医学背景；事实提取与事实复核禁用网页搜索 |
| 诊断包 | 用户选择的本机路径 | 不自动上传；不含健康正文、姓名、路径和凭据 |
| 备份 | 用户选择的本机路径 | 应用不上传；由用户自行保管加密文件 |

界面中的“已发送”来自持久化发送审计，不根据文档状态猜测。退出 Codex、停用目录或取消任务会使后续提交门禁失败；已原子保存的历史事实保留。

Web Search 搜索词不得包含姓名、完整日期、报告原文、本机路径、内部 ID 或可唯一识别个人的事实组合。搜索结果只能用于解释通用医学概念，不能替代、修改或补造报告事实。本地命令沙箱仍保持无网络。
