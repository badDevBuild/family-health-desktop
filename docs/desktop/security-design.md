# 安全设计

应用默认本机保存健康资料，只在用户明确授权后把必要片段发给 OpenAI/Codex。手动批次授权与目录日程授权分开，并绑定成员、文档范围、阶段与当前账户指纹。

硬门禁：

- 每次模型调用前后都检查任务、attempt、授权、账户与取消标志。
- 最终发布在同一数据库事务内再检查执行栅栏，防止迟到结果。
- AI 发送记录区分 `sending`/`completed`/`unknown`；异常不会被伪装成“未发送”。
- 渲染层无 Node 权限，IPC 校验发送者和输入 schema，文件预览不暴露本机路径。
- 备份使用口令加密，恢复前校验数据库与对象哈希。

应用不将模型输出当成信任边界：人员身份、来源覆盖、引用内容、数值一致性、日期和医疗表达边界都由本地规则复核。

漏洞报告方式见根目录 [`SECURITY.md`](../../SECURITY.md)。
