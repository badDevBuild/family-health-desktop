# 纯合成金标与安全故障数据集

## 当前结论

工程内已固定 `family-health-synthetic-gold-v1`：40 个纯合成来源包、1,000 个可评价字段、8 个留出来源和 18 个安全/故障样例。数据由确定性代码生成，不包含真实成员、医院、报告、路径或账户资料。

当前 CLI 在干净目录物化 83 个文件：40 个来源 JSON、40 个真实格式夹具、1 个安全样例文件和 2 个 manifest。结构化 manifest SHA-256 为 `e4c3667a6ebdde450c2b7e0d4123c3f78a7e4e70997561bf666310196a929338`；当前 darwin-arm64 二进制夹具 manifest SHA-256 为 `e55058615441f8ab84d50659476eca2de7bea9867fdfadbe432de97429cf875f`，连续两次生成一致。这些哈希只证明合成数据包和当前平台夹具可重复生成，不是模型准确率或专业复核证明。

这一步完成了“评测资产结构、真实格式夹具和计算口径”的当前 Mac 本地门禁，**不代表真实 Codex 模型已经达到医疗准确率目标**。40 个夹具由魔数检测为 6 PDF、6 JPEG、6 PNG、6 HEIC、6 DOCX、5 OLE DOC 和 5 UTF-8 TXT；应用的导入检测器也逐一识别成功。代表性 PDF 可读取并栅格化 3 页，DOCX 可读取 53 个文本/表格/图像单元并导出 1 幅嵌入图，HEIC 可解码 1 幅图，旧 DOC 可读取 29 个文本块。后续仍需在获授权测试账户和三个目标平台上运行真模型，并由独立专业人员复核标注与结果。

## 固定覆盖

- 来源包：40
- 标注字段：1,000（每个来源包 25 个）
- 留出集：8 个来源包，即 20%
- 格式目标：PDF、JPEG、PNG、HEIC、DOCX、DOC、TXT 均至少 1 个
- 内容特征：数字/定性/比较值、日期、不同参考范围、同日多次就诊、跨页、旋转、模糊字符、身份冲突、中英混合、报告所述诊断边界
- 安全与故障：18 个，覆盖提示注入、shell/网络/插件请求、宏、路径穿越、symlink/junction、持续写入、截断流、重复事件、迟到结果、磁盘满、数据库锁和恶意备份等

## 指标必须分开

评测器分别输出：

- 自动接纳字段精确率
- 可读字段覆盖率
- 成员错误归属数
- 伪造证据数
- 把 AI 推断升级为医生确诊的违规数
- 自动开药或调整用药的违规数

没有候选输出时，精确率和覆盖率都记为 0，不能用全部 `unknown` 换取“零错误”。Beta 放行仍要求固定来源二进制、真实模型回执、三平台执行以及独立人工/专业复核。

## 机器门禁

`packages/evaluation/src/index.test.ts` 验证来源数、字段数、留出比例、格式/特征覆盖、故障样例数、ID 唯一性、结构化物化确定性和指标计算。CLI 另外生成真实二进制夹具、逐文件 SHA-256 与魔数回执；HEIC 和 OLE DOC 的生成在当前实现中调用 macOS 自带转换器，因此生成步骤目前限于 macOS，但产物可复制到隔离测试机。物化只写入调用方指定目录，不提交二进制测试报告，也不会读取家庭健康工作区：

```bash
pnpm gold:materialize -- /tmp/family-health-synthetic-gold
```
