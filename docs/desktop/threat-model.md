# 威胁模型

保护对象是原始健康报告、成员归属、已接纳事实、用户补充、Codex 授权边界、审计链和备份。主要信任边界包括渲染层↔主进程、本机文件↔规范化器、应用↔Codex App Server、当前工作区↔备份。

主要威胁与控制：

- 错人归档：报告明示姓名与目标成员冲突时转人工；无姓名报告只能依赖可审计的用户/目录归属。
- 模型编造或引用错位：校验 span ID、引用文本子串、数值与日期；视觉证据保留独立双读与人工出口。
- 重试重复写入：每个文档有稳定提交键和唯一提交记录。
- 取消/撤权竞态：每次外部调用前后和最终事务内重新验证执行栅栏。
- 恶意文件或资源耗尽：类型检测、大小/页数/解压预算、受控临时目录和超时。
- 渲染层越权：上下文隔离、禁用 Node 集成、最小桥接、发送者检查与 schema 校验。
- 备份篡改或路径逸出：加密、解密后整体校验、对象哈希校验、恢复交换前路径约束。

剩余风险：未签名 Beta 包的供应链信任、第三方解析器未知漏洞、图像证据无法靠纯文本规则完全确认。公开发行前仍需签名/公证、目标机实测和依赖安全响应流程。
