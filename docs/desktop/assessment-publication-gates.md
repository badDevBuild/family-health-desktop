# 成员综合的发布门禁

本文件说明 `dashboardApp` 当前源码的综合发布流程（2026-10-26）：`member-assessment-v51`、`assessment-validation-v43`、`lean-health-v3.61`。它不证明已安装版本、某次任务已经完成或真实医学内容已通过验收。原件直读另用 `extract-direct-original-v23` / `direct-original-acceptance-v22`，不因综合修复而重新提取。

产品目标是上传后自动得到完整、可用的健康看板。后台校验、局部修复和语义复核由应用完成，不让家庭成员逐条批准。这里的“完整”是可靠内容及其真实范围都完整呈现，不是强行把每条候选变成已确认结果。空白、读不清、日期未知或只有波形的原件保留说明，不能冒充正常，也不能为了消除缺口编造。

## 四类门禁

### 重点问题的变化与实际意义

重点主题按 `topicKey` 组织，至少有一条代表主张回答目前状态、与过去相比的变化、现实意义与下一步。可选 `changeAssessment` 保持旧快照兼容，新生成的重点解释需填写改善迹象、更需关注、基本稳定、不同维度变化不一、不能判断或没有对应历史，连同原因及真实新旧引用。没有程序 `TrendFacts` 不再阻止有证据的定性比较；程序数学结果仍用于精确变化，不自行生成百分比或风险分数。

本地检查引用存在、属于本主张、两侧不是同一事实，以及变化结论确有两侧依据；跨方法、单位、参考范围和人群等医学可比性由模型结合全量资料判断，变化解释并入既有一次 P04。不能把参考范围内波动、免疫标记物升降或不同影像措辞直接当成整体病情变化。报告日期投影及原始检查值继续保留，不借分析改写原数据。

重点主题没有变化解释时，与既有局部 P03 合并补写一次，共享原来的有限修复预算。解释仍缺失则记录 `comparisonCoverage.missingTopicKeys` 并在该系统提示，不撤掉其他有依据的结论或建议；该记录仅表示结构覆盖，不证明医学完整性。只有存在错误引用或实际不支持的断言才沿既有证据校验处理。主页与系统详情均展示变化的范围及理由，不单独显示一个没有条件的好坏标签。

覆盖范围以 P02 原始重点主题为基线，并保留最终重要或紧急主题。摘要因局部隔离而从所有存活记录重建，不把其中常规记录自动升级为新增重点；原重点被隔离时仍记录真实缺口。解释中的连续或并列年份按日历语法识别，可用本人已引用原始日期支持年份投影；检验数值、指数、单位、数字标识及来源事实的日期角色和精度不借此改变。

一般医学含义、有限的关联解释及低风险日常起点允许使用明确分级的通用知识，不要求每句话重新取得指南。影响诊疗阈值、临床时点及个体治疗操作的依据要求仍在。个人补充触发完整重新理解所有相关分析与五类建议，未知只限制真正依赖它的部分，不把独立建议一并拦下。

四类职责不同，不能把任何不匹配都当作整批失败，也不能把模型说“通过”当作所有硬约束的豁免。

| 类别 | 检查对象及代表约束 | 未通过时的范围 | 能否交给模型解决 |
| --- | --- | --- | --- |
| 全局执行与范围 | 授权用途、账号、成员、任务状态、取消/撤权、原件哈希、事实与背景版本、开放核查范围、输入签名；Schema、唯一 ID、系统集合、精确目标回执、容量 | 停止对应发送、合并或发布；没有可信唯一范围时不能靠删节点继续。已有报告事实及旧结果保留 | 模型不能更改授权、成员、版本或目标权限；合法目标内的结构修复仍须重新校验 |
| 局部内容与依赖 | 真实来源存在、来源绑定、个人证据、数值与比较符、完整单位、部位/左右侧、否定与检查条件、日期角色、诊断分型、用药边界、行动时间、过程叙事及引用闭包 | 能唯一归属时只隔离该节点及真正依赖它的节点，必要摘要由仍可靠内容重建；无法定位或仍有全局歧义则拒绝新综合 | 有限 P03 可修获准目标；不允许改已接纳事实、扩大范围、机械删引用或伪装成一般建议 |
| 语义复核 | 来源是否真的说明诊断/医生安排、问句的个人事实前提、个人习惯建议是否与真实来源相符、高影响解释、标准适用与医疗随访时间 | 无实际通过凭据或新正文越界时，只保留对应未发布范围；独立合格内容继续 | 合并为主 P04；日常建议仅有下文定义的有限最终前提复核和后置改写复核。模型判断不能跳过左侧两类硬约束 |
| 知识归属 | 目录来源 ID、规范书目、来源实际支持的解释范围、标准来源与个人证据的角色、检索来源可核查元数据 | 普通解释引用不成立时仅撤引用；有引用的无效来源继续严校验；未被任何正文/标准引用的坏元数据单独移除 | 普通知识专用目标只有知识字段修正权，没有医学正文改写权；标准与医疗时间不能撤引用后继续当作已证明结论 |

全局检查在任务领取、每次模型发送前后和最终事务再次执行。可选补救阶段发生短时服务失败时，也必须重查取消、授权和版本；只有服务故障可以局部降级，真实执行边界不能被吞掉。

有唯一真实节点归属的 `unsupported_high_impact_text`，包括行动和问题，按整条节点隔离并重建受影响摘要，不再因节点类型拖住独立合格内容。它不是放行高影响断言：原句不发布，节点 ID 前缀不授予权限；未知目标、重复 ID 或全局范围错误仍不能局部降级。

## 各类内容如何处理

| 内容 | 必须保留或证明什么 | 自动处理后的边界 |
| --- | --- | --- |
| 来源事实 | 同成员已接纳事实及真实来源；数值、比较符、数量级、单位、部位、否定和解释条件 | 综合只引用和解释，不回写测量结果。数字标识不是检验数值，但也不能换成其他项目 |
| 时间 | 检查、签发、住院边界、历史记录与当前状态的角色不同 | 不能凭时间接近或同一文件擅自改派操作日期；时间不明只限制真正依赖该时间的结论 |
| 原报告安排 | 指向单条已接纳文字事实的 `sourceInstructionObservationId`、原动作、原期限及条件 | 原句可保留，是否为该成员指示及历史适用性由语义复核判断；不是自动批准今天执行，也不是生成新处方的权限 |
| 个性化日常 habit | 常规、非医疗、有个人依据，来源可直接定位或经存活关联主张定位 | 仅缺自身 `evidenceIds` 时可送 P04 读真实来源；不允许两个候选节点互相证明，不因字段非空直接发布 |
| 一般日常 habit | 无个人肯定病情、医疗安排、用药操作或新增补充剂指令，明确为一般建议 | 不能把被隔离的个性化正文换成 `general` 标签绕过来源；一般内容在页面与个人结论区分 |
| 高影响判断与行动 | 明确分型、个人证据、标准及适用条件；确定性和紧急程度不越界 | P04 可在同一医学范围内纠正表达，不能凭目标 ID 放行新病名、新标准、升级确定性或新的医疗操作 |
| 关联行动、问题与摘要 | 只依赖实际支撑其正文的主张；问题的已断言前提也要核对 | 失效主张不能继续替旧正文背书。独立内容不连坐，受影响内容不靠删边“修好” |
| 目录与检索知识 | ID、正文支持范围及归属正确；标准必须来自已提供且适用的目录 | 普通引用不符只撤引用；检索网址目前只标为模型引用，不冒充已验证网页正文 |
| 重复、无效书目 | 先看是否被主张、行动或诊断标准实际引用 | 无引用坏条目可移除；引用中的坏条目仍需校验。重复 ID 的前置规范化存在下述限制 |

已记录诊断中的复合病名、共同部位省略和标题缩写可能超出本地文字比较能力。有唯一、可定位的真实个人来源，且同一主张只有诊断归属或标题对应疑点时，交给本轮已有的 P04 逐项核对，不要求所有诊断挤在同一句原文。它不自动证明诊断：真实栏目、主体、否定、确定性和时间仍要成立，不能只信模型提取的项目名。没有绑定完整最终节点及依赖的有效语义回执，原门禁继续生效；其他硬错误、一般标题和汇总标题不借此豁免。

历史用药记录中的“不表示今天应开始、续用或停用”属于否定说明，不是正向改药指令。否定只约束对应动作；同句转折、重新发出的命令和双重否定不能借前文获得豁免。识别到来源语义疑点时，仍须读取真实个人来源并完成 P04，不能仅因消除了字面误报就发布历史处方。

“注射液、口服液”等剂型名词不因字面包含给药动词就冻结整段检验解释。名词记录及其历史、否定、条件和后续内容仍完整保护，只将可证明独立的测量解释从用药操作签名中分离。真正的服用、注射、剂量、频次或当前执行要求继续检查；不允许借背景修正删除“不代表当前需要”的限制，也不允许扩展建议的身体系统范围。

“未提供某疾病的诊断记录”说明资料范围，不是已经确诊，也不证明已经排除疾病。高影响断言识别区分缺资料谓词与诊断名词宾语，只在当前对象和并列范围内绑定否定；转折后的新肯定、“不能排除”、双重否定与其他对象仍按各自语气检查。这个分类修正不会改写正文、来源或正式事实，也不豁免真正的诊断分型、个人证据和语义复核门禁。

“不能单独诊断”及带依据短语的“不能仅凭……诊断”属于诊断能力限制，不得因中间的方式或依据描述丢失否定。相反，“不能仅凭……排除”仍表达未排除的可能性，需要保留高影响复核。两者以分句内的模态与终结谓词分类，不按固定字符距离截断；新主体、新断言和转折后的肯定仍独立检查。

“这不是……的诊断”中的诊断名词仍在否定范围内，纯并列对象共享此否定；双重否定或后续独立肯定不能借此豁免。“检查前用药条件不完整”是资料限制，实际用药操作、剂量与频次仍单独保护。对解释中错误的“方法未提供”，P04 可用 `source_context_text` 提供本次已引用个人来源中的唯一连续项目/方法原话，绑定原候选、替换候选、来源哈希及指定解释字段；只允许补入该原话中的数字标识，结论、比较方向、日期角色、个人引用和其他数值不取得修改权限。这个证明不代表程序能自行判定所有医学方法名，仍要求 P04 核对分类、其他未知和适用条件。

### 无依据日期只撤回，不另猜时间

来源能证明发生过检查、操作或结果，但正文中的具体日期没有证明时，P04 可执行一个窄修正：

- 只从 `source_fact.text` 撤回无依据的日历日期。每个日期作为完整片段，只能原位保留或整段撤回；同一正文中其他有独立依据的日期可原样保留，不新增或变更年月日、不降低精度、不从多个日期拼出新日期。没有年份的有效中文月日也属于日期，不算作检验测量数字；不能因此补出年份。
- 日期可以连同附属的纯文档时间修饰语完整撤回。应用按日期、介词、文档元数据角色与结构助词的组合语法定位精确范围，不按报告模板逐句放行，不允许任意删除日期旁的文字。检查、采样、手术、服药及术后条件属于临床含义，不在可删元数据角色中。
- 除上述纯时间修饰外，非日期正文仅允许等价字符与空白差异；实际测量数字、单位、比较符、顺序、事件、部位、否定和条件均保留。其他医学、证据与知识字段不随之改变。
- 明确 `temporalStatus=uncertain`，保留原不确定说明，并说明相关日期未确认。说明允许自然结构助词与日期精度修饰，所指报告或事件仍须锚定已有正文或来源；只能表达时间未知，不能附带新疾病、用药、数值或事件。模型优先使用中性日期说明或已有来源明确定位的报告文类，不从多个文档拼接新的复合事件或标本、操作角色。
- 原正文中的完整时间角色限制保留，例如不能把报告时期当作操作日；未知说明追加到 `materialUncertainty`，不能替换或概括原限制句。模型越过此权限删除否定或临床条件时继续隔离对应目标。
- 完整本地校验与 P04 的真实语义判断仍然必要；这个例外不是“日期都不重要”。

完整日期改成猜测月份、用出院月替手术日、不同事件拼成一个时期、删除非日期数值或删掉医学限制仍不通过。时间归属或精度变化记为 `date_scope_or_precision_changed`，与真正的测量值改变分开记录。该修正只改变综合候选，既有报告事实、事件日期与时间线不会因此被修改。

依赖术后天数、停药时点、医疗复查期限或“目前仍然如此”的建议，不能因日期被撤回就照常执行。与该时间无关、有独立个人依据的日常建议可保留或在限定范围内实质改写。

### 系统关注状态与内容完整性分开

系统摘要因局部内容被隔离而重建时，先回退为中性，不能从剩余条目数量推断“正常”或“建议关注”。如果隔离前本批已有 `attention` 或 `monitor`，且仍有同系统、同成员的存活个人来源支持，可将精确原状态交给同批主 P04 明确复核。只有显式替换为该原状态、依赖闭包仍有效且完整边界校验通过，才允许恢复；普通目标没有修改状态的权限，`stable` / `no_signal_in_scope` 不通过这个例外恢复。

`rebuiltNodeIds` 记录摘要曾被重建，`interpretationState=partial` 表示解读范围仍不完整，两者不能永久盖掉已重新复核的真实关注状态。未得到有效复核、无存活个人支持、唯一关注主张被隔离或模型明确 hold 时，继续保留中性说明，不自动恢复旧状态。

### 补齐已知依赖与新增来源分开

主 P04 可以为既有行动补齐同批已经提供的主张关联，前提是它属于完整临床复核目标、应用明确授予 `actionDependencyRebindings`，模型显式 replace，并核对该主张真实支持、反证与时间条件。关联仅能指向本次 P04 目标或只读上下文中的唯一主张；只读主张保持冻结输入不变，目标主张可以由同次 P04 合法收窄，但必须独立通过原有边界和来源检查。应用随后冻结这份合法的 P04 最终主张内容。不能从数据库其他结果、旧快照、未提供的主张或被 hold 的节点中新增关联，也不因来源部分重合而自动成立。

这项例外只整理依赖：行动除 `claimIds` 与按既有规则收窄的知识引用外，全部字段保持原样，包括所有展示正文、直接个人来源、身份、分类、系统、紧迫度、时序及原医嘱绑定。直接新增来源、改写正文或提高确定性仍走原有拒绝规则。最终完整校验和依赖哈希仍运行；后续 P03、隔离或其他修改改变前提会使资格失效。仅知识引用目标与后置日常建议补救不取得此权限。

## 有界的后台修复流程

1. P02 一次读取完整成员分析包，生成整体解读、系统解释、五类日常建议、医疗安排与必要问题。
2. 本地先做全局、局部与知识检查。有可修问题时调用限定目标的 P03；常规前置与后置修复共用最多两次 P03。有唯一真实个人来源的解释正文若声称资料缺失，同批前置 P03 也对照完整来源原话核查；路由不表示已证明错误，无法纠正时保持原文，不能仅因这条软检查就隔离。已有方法名称等事实在此纠正后，P04 看到完整的新候选，真正未知的用药背景与检查条件仍保留。其他解释字段沿既有 P04 来源证明处理，不因常规未知提示额外撰写整批。修复回执必须绑定成员、输入签名、原候选哈希和逐一完整的目标集合，非目标原样保留。
3. 高影响、临床问句前提、可审查语义疑点及知识归属合并为一次主 P04。目标外的相关主张以 `readOnlyClaims` 及其真实支持/反证来源提供，只供理解，不取得替换权。
4. 对 P04 的最终正文再次检查医学范围、实际依赖和完整本地规则；不能因编号已复核就沿用旧通过凭据。不能证明的节点局部隔离，独立内容继续。
5. 原 P04 通过的日常行动正文完全不变、但存活前提被后置修正时，对有真实个人依据的常规 habit 最多再做一批 `final_habit_premises` P04。只接受绑定最终依赖的新 pass，替换、隔离或不完整回执均不沿用旧通过；这批行动不再进入后置改写补救。
6. **仅当主 P04 后本地门禁才发现前提失效时**，对原 P02 已有、因依赖失败被隔离且仍有独立个人依据的其他低风险 habit，最多再调用一批 P03 加一批局部 P04。这一批不重跑 P02 或整份 P04，也不会循环再救援。
7. 所有主张和行动定稿后，只有因局部隔离而重建、并且仍需汇总多个有效主张的整体/系统摘要，才能再使用一批 P03 撰写连贯概况、一批 `final_aggregate_summary` P04 核验。只有单一主张时直接呈现其完整说明，不追加摘要调用。范围限原摘要引用中仍有效的内容及原行动的最终前提，不把回退时加进来的常规记录升级成新重点；叶子内容、状态与必要条件冻结，摘要引用只能收窄。复核只接受绑定最终依赖、完整目标及同一成员输入的 pass，不接受再次改写。新增事实、恢复已隔离内容或复核失败时保留可靠分项与中性说明，不重复调用。
8. 最终事务重查执行范围与事实/背景版本，发布版本化综合快照；事实提取完成与综合发布分别有结果回执，不能把处理完报告当作综合已更新。

因此，普通路径最多两次 P03、一次主 P04；最终前提复核另最多一次 P04，有资格的后置补救另最多一次 P03、一次局部 P04，这两类行动目标互斥。最后的退化摘要重建另最多一次 P03、一次 P04，最坏路径可能达到四次 P03、四次 P04；没有问题不为凑额度而调用。旧记录条件补齐、报告提取与任务级有限服务重试有各自契约，不把它们混入“所有场景只需两次调用”的承诺。

综合阶段的持久回包先校验必需结构，再对原始完整回包核对摘要。运行时附带的耗时、用量等字段也属于完整性校验范围，不能先由 schema 投影删除后再算摘要，也不能忽略它们被改写的情况。有效回包保留原字段与顺序供后续契约复核；输入、授权、版本和有限传输预算仍须匹配。后段失败时复用已完成的分析，不重复发送成功阶段。

“仅更新健康解读”的新请求意图与资料签名分别去重。同一授权重复提交始终复用原任务；已有运行中的同签名任务也复用，不并行重复发送。用户重新发起更新且旧任务已结束时，以本次授权建立新的仅综合任务，不因资料未变化而撞上旧任务唯一键。旧任务、未知回执和已保存结果完整保留，普通断点重试仍不把终态未知当成请求未发送；新的综合授权仍硬禁止原件读取和事实改写。

### 后置独立建议的额外限制

- 只能处理 P02 已有行动，不能新增 ID、领域或缺失的第五类建议。模型明确 hold 的行动、行动自身越界的内容不进入此通道。
- ID、类型、去重键、身体系统、生活领域、个人依据类型、时间依据保持。个人支持只限原行动直引的来源及其原关联、仍存活主张的支持原文，并须在本轮 `remainingEvidenceIds` 明示；应用在发送前冻结原行动、成员输入、存活主张与来源哈希，替换后再次校验。原已明示闭包中的支持原文可直接绑定行动，不把原间接引用误当成新的个人资料。知识仍限原集合；被隔离主张、仅作为反证的来源、新关联、未提供或身份不明的来源均不得借此扩入。同一原文已同时提供支持与限制时保留完整语义，由 P04 核对，不能删掉限制再使用。
- 必须完整改写失效理由、做法、时间与限制中的实际问题；只删依赖、换排版或改元数据不算实质重写。原医生安排、处方操作、医疗复查、新补充剂及高影响行动不借此恢复。
- 原有完整安全句保留时，仅追加独立的非医疗时间说明不算新增原安全句中的医疗动作；不能因整段注意栏变化就误判。修改原条件、拆句、跨字段搬移或追加新的医疗操作不取得此例外，仍须完整语义复核。
- 最终仍引用的主张必须存活。局部 P04 读取实际的新正文及真实来源，精确覆盖这批目标；缺失、重复、错成员、错签名、错类型或越权替换不合并。
- 通过凭据绑定最终节点、成员输入及当前主张/知识依赖。后改正文或依赖不能复用旧凭据；失效内容只影响其实际依赖闭包。
- 后置补救恢复行动时，必须同时闭合它仍保留的知识引用。前段因暂时无引用而清理的目录元数据，只能从本次输入中唯一、完整的同一目录条目恢复；不新增知识引用，不借旧快照、相似标题或 URL 猜测补齐。恢复后的实际正文和完整来源仍交给局部 P04 与本地门禁核对。来源曾被判定不支持而移除的引用、未知目录、缺失正文或没有工具回执的外部检索条目，不能靠补元数据变成有依据或已读取。
- 最终发布候选的知识引用必须全部落在自身保留的书目中；本次输入中存在某个 ID，不等于最终快照已经包含它。存储的完整引用校验保持不变，不能通过删引用或放宽校验来绕过闭环缺口。
- 可选阶段遇到模型繁忙、连接失败或超时，保留对应建议缺口，让已有合格结果发布；取消、撤权、资料版本变化、未知程序错误仍停止不安全发布。主分析的服务失败不因此被改称局部成功，仍走正常任务失败与有限恢复机制。

五类建议缺失不是追加模型回合的触发器。页面可说明未发布范围，不用模板、一般建议或新模型补写冒充个人完整结论，也不要求用户反复批准。

## 正文中的外部知识链接

对本次已经实际使用的官方公共知识网址，应用在已授权联网的综合中进行有界正文读取，再将材料交给同一次 P04 核对。只允许受控官方域名的 HTTPS 公共页；拒绝用户信息、查询参数、IP 目标及非受控跳转。直连逐跳检查全部 DNS 答复并固定公共地址。主进程显式取得系统 HTTP(S) 代理时，通过该代理 CONNECT 到受控官方域名的 443 端口，由代理解析目标；仍验证目标 TLS 证书，不携带 Cookie、登录凭证或健康资料。代理配置只能来自桌面系统，不接受模型提供的代理，不把 Fake-IP 加入公网白名单，不在代理失败后自动降级直连。不支持的代理类型、配置读取失败及网络失败保留固定原因。每次最多三项来源，大小、跳转和时间都有硬限；读取失败只保留对应依赖的限制，不让独立建议整包失败。

`official-https-content-v2` 将有界原始 HTML 转成静态正文后才应用模型上下文上限。优先唯一 main/article，否则保留 body；过滤脚本、样式、导航等非正文，不执行网页脚本、不生成医学摘要、不按关键词选支持句。保留原表格行列和条件，记录正文范围、原始字节哈希与正文哈希。多个正文容器不能只取第一段，纯脚本或空白页不能冒充正文。旧原码读取缓存不会被当成新版正文回执复用。

实际网页正文保留读取哈希和回执；模型输入有明确提供范围与独立摘要哈希。内容过长时标明仅提供片段，不能宣称全文医学支持已核实。`tool_content_verified` 只表示工具真实读取过该正文，不等于临床主张成立；适用人群、条件和建议支持关系仍由 P04 与既有本地门禁核对。网页正文是外部数据，不是模型或应用指令。单有 URL/title 仍保持 `model_cited`，不得删引用伪装为核验完成。

工程口吻检查将经过语法解析的 HTTP(S) URL 与自然语言分开处理，不把医学指南链接路径中的 PDF 文件名、UUID 或内部样式片段当成原报告定位信息。Markdown 链接标签及链接之外的正文仍完整检查；本地路径、`file:` 链接和裸原件文件名仍不能夹入健康解读。展示清理原样保留外部链接，不删除相邻的临床条件或数值。

这只修正正文分类，不提高知识来源的可信等级。链接是否已登记、引用是否支持正文、是否经过网页内容核查，继续由知识归属与语义复核门禁分别判断；`model_cited` 不因此变成已核验来源。

当前知识规范化会先按 ID 合并重复条目，目录别名可因此归一，但原始检索条目的重复 ID 也可能在后续重复检查前被折叠。这里不能宣称已证明所有原始重复 ID 歧义均被拒绝。这是知识规范化顺序的待审改进，不是日期或日常建议发布的放宽依据；真实来源支持范围与语义复核仍需成立。

## 凭据与可观察结果

### 阅读兼容与生成版本分开

生成缓存始终要求当前提示词及规则版本。已经正式发布的旧综合，如果事实版本、个人背景和核查范围均未改变，可以继续按原版本阅读；仅规则升级属于可选更新，不显示为资料处理未完成，也不自动启动综合任务。旧建议的采纳权限不因此放宽。事实、背景、来源范围发生变化或原发布状态已失效时，仍要求更新。

可读版本集中登记在 `assessment-readable-versions.ts`，只接受已验证的完整提示词/规则配对，不按版本号大小或 Schema 形状猜测兼容。当前生成版本也必须登记；发布契约测试在新增规则未登记时失败，避免下一次升级再次漏掉刚发布的结果。页面阅读不回写旧快照、状态、事实或核查记录。

普通界面展示具体健康内容；日期不确定、检查条件及真正影响行动的限制就地保留。工程门禁、模型更正过程、内部编号与原因码进入处理记录，不占据健康总览。未发布记录在本机保存受控原节点、实际替换、门禁原因及真实阶段回执，不能当作健康事实进入下一次分析，也不写入公开代码或日志。

局部 P04 只有结构、范围及替换应用成功后才记录正式回执，避免无效回执污染后续审计。动作被补救后最终状态应反映实际发布结果；模型通过不等于本地通过，本地通过也不等于真实医学内容已验收。

## 等价表达、证据修正与局部缺回执

- 综合显示中的十进制小数尾零可规范化（例如合成值 `1.00` 与 `1`）。使用字符串精确比较，不做浮点近似、单位换算或四舍五入；比较符、正负号、科学计数法量级和完整单位仍受保护，正式事实原值不改写。
- P04 可返回可选 `evidenceResolutionProofs`。直接来源改绑必须由本次实际提供的两个引用证明同一已接纳事实与同一原件位置，且临床正文不变；同页、同值、模型说“已核实”或反证不能代替证明。
- 单一“某信息未提供”的 `materialUncertainty` 可撤回该缺资料断言，但只能逐字换成冻结来源中的完整连续“字段：值”原话，不能置空或推断该值已明确。栏目写“无”“未说明”“未见记录”或为空也完整保留，不用非空字符串或缺失词黑名单猜语义。其他临床正文不改写，复合未知、真实检查条件、时序、药物或人群限定不能随缺口一起撤掉；证明失败仍隔离或保留说明。
- P04 身份和输入签名有效、回执唯一且没有未知目标时，遗漏目标只产生本地 `review_receipt_missing` 隔离项。其实际依赖沿正常闭包处理，独立合格内容可发布；不能把本地隔离记录成模型 hold/pass 或记入已复核目标。重复、未知目标或错范围仍整份拒绝。
- 综合拒绝路径将固定白名单原因码、输入签名和计数写入本机审计；自由错误、节点正文、URL 与原始报告内容不进入该诊断。任务结束清理回包缓存后仍能查到技术类别，旧任务不补造历史原因。
