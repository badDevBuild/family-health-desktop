## 已关闭的旧风险

- Codex arm64 运行时已捆绑并在成品启动，不再是“运行时缺失”。
- PDF 扫描页、HEIC/HEIF 和旧 DOC 转换适配器已有首版实现及测试，不再是代码功能空缺；旧 DOC 可分发签名组件、跨平台与许可仍单独保留。
- 品牌图标已进入应用包，`Info.plist` 指向生成的 `icon.icns`。
- 加密备份/原子恢复与自动恢复点已经实现，不再只有 SQLite 备份接口。
- 报告删除已实现当前工作区事实/证据/派生/发布历史级联、双重确认、任务门禁、恢复点引用保护、导入 tombstone 与“重新允许导入”；界面明确不承诺擦除既有恢复点、外部加密备份、系统备份或云盘副本。
