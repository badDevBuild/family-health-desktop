# Lean V3：当前自述症状的提前提醒

这是 M13 的一个受限实现，不是急症筛查器。成员当天在本人补充资料中明确写出“正在/目前/现在/今天持续胸痛并伴大汗或冷汗”时，成员页在 P02 完成前显示条件式急救提醒，标明来源是本人自述，**不写入确诊病史，也不推断心梗**。旧报告数值、旧症状、否定句、假设句和不同句子拼接不触发；跨过当天后不再把这条旧记录呈现成当前发作。没有横幅绝不意味着没有急症。

本地判断只回显有限的时间与症状组合；如仍在发作，界面提示拨打 120、不要自行驾车。国家卫健委[2025 年新闻发布会](https://www.nhc.gov.cn/xcs/c100122/202511/b622555670fa4f2388eb35f1c339195f.shtml)对剧烈胸痛、高度怀疑急性心肌梗死时的拨打 120 和避免自行驾车有明确说明；[美国心脏协会](https://www.heart.org/en/health-topics/heart-attack/warning-signs-of-a-heart-attack)把持续胸部不适及冷汗列为需及时呼救的警示症状。本应用既不据此确认病因，也不把“本人记录”标成医院资料。

验证范围：`current-symptom-notice.test.ts` 测当天/旧日、否定/假设/历史语境；`workspace-service.test.ts` 测无 P02 也可读取；`MemberProfileV2.test.tsx` 测可见横幅及条件式行动。真实用户旅程、医学专业评估与安装包界面检查：**NOT_RUN**。
